irAE 器官分級處置速查

免疫檢查點抑制劑相關不良事件 —— CTCAE v5 分級 × ICI 處置 × 類固醇/二線用藥,依器官系統彙整
架構 ASCO 2021 · NCCN · ESMO 2022  |  整理 2026-08

⚖ 共通原則(先讀)

  • 類固醇前先排除感染(糞便 C. diff/CMV、痰液/PJP、病毒性肝炎)—— 類固醇會蓋掉感染表現
  • G2 起暫停 ICI;G3–4 多數器官永久停用(內分泌補足荷爾蒙後為主要例外)
  • 類固醇 48–72h 無改善 = steroid-refractory → 上二線(各器官不同,見各卡)
  • 改善至 ≤G1 後 4–6 週緩慢 taper(太快減 = 復發主因)
  • 類固醇 >4 週:PJP 預防(TMP-SMX)、鈣/VitD、血糖與胃黏膜保護
  • Combo(CTLA-4+PD-1)irAE 更早、更重、更多器官 —— 監測閾值下修
  • Rechallenge:心肌炎/神經/G4(非內分泌)原則不再挑戰;G2–3 緩解後個案評估(復發約 25–30%)

    🧮 類固醇等效換算(glucocorticoid equivalence)

    錨點:prednisolone 5 mg ≡ methylprednisolone 4 mg ≡ dexamethasone 0.75 mg ≡ hydrocortisone 20 mg
    任意換算(IV→口服 taper 轉換用): mg
    irAE 情境開方: kg
    作用時長:hydrocortisone 短效(8–12h)/prednisolone·methylprednisolone 中效(12–36h)/dexamethasone 長效(36–72h)→ 長效藥 taper 節奏不同。 ⚠ dexamethasone 幾乎無礦物皮質素活性——腎上腺功能不全的「替代治療」以 hydrocortisone 為主(原發性另加 fludrocortisone),不可以 dexamethasone 等效換算充當替代;本表為抗發炎效價近似值,處方依院內規範取整至可調劑劑量(MP 針劑常見 40/125/500/1000 mg 規格)。指引 G2 多以 prednisone 當量表示、G3–4 直接以 methylprednisolone mg/kg 表示——同單位直接開立,換算主要用於 IV→口服 taper 交接。

    💊 免疫抑制劑藥理學(irAE 二線 / steroid-sparing)

    類固醇無效或需減量時的第二線藥物,依「作用機轉」分類。共通紀律:上二線前先排除感染;起效速度決定重症用藥選擇;多數藥有 HBV/TB/感染監測需求。
    藥物標靶 / 機轉起效irAE 主用途關鍵注意
    ◆ 基石:皮質類固醇
    Glucocorticoids
    (pred / MP / dexa)    		GR 受體 → 基因體效應(轉抑制 NF-κB/AP-1 → ↓發炎細胞激素)+ 高劑量脈衝之非基因體快速效應數小時–1–2 天
    (高劑量脈衝分鐘–小時)    		所有 irAE 一線感染/PJP 預防(>4週)、血糖、骨/胃;劑量換算見上方工具
    ◆ 嘌呤合成 / T 細胞增殖抑制
    Mycophenolate (MMF)抑制 IMPDH → 阻斷 de novo 鳥嘌呤合成 → 選擇性抑制淋巴球增殖慢:3–14 天
    (需耗竭淋巴球增殖)    		肝炎二線首選、難治腎炎/肺炎肝炎不用 infliximab 故選它;追 CBC、腸胃不適
    Calcineurin inhibitors
    (tacrolimus/ciclosporin)    		抑制 calcineurin → ↓IL-2 → ↓T 細胞活化數天(2–5 天)
    依血中濃度    		難治肝炎、皮膚、神經監測血中濃度、腎毒性、電解質
    ◆ 細胞激素標靶單株抗體
    Infliximab (anti-TNFα)中和 TNF-α快:1–3 天
    (24–72h)    		結腸炎二線首選、肺炎、關節炎⚠ 肝炎禁用(肝毒性);先篩 TB/HBV;中重度心衰禁用
    Tocilizumab (anti-IL-6R)阻斷 IL-6 訊號快:數天關節炎、CRS、部分難治肺炎腸穿孔風險、LFT/血脂、感染;IL-6 降會遮蔽 CRP
    ◆ 淋巴球輸送(腸道選擇性)
    Vedolizumab (anti-α4β7 integrin)阻斷淋巴球歸巢至腸黏膜 → 腸道選擇性,幾乎不造成全身免疫抑制較慢:1–2 週
    (較 infliximab 慢)    		結腸炎(與 infliximab 反應率相當、類固醇用量更短、復發更少)不想全身免疫抑制、或抗腫瘤疑慮時的優選
    ◆ T 細胞共刺激 / 訊號阻斷(重症,尤其心肌炎)
    Abatacept (CTLA-4-Ig)結合 CD80/86 → 阻斷 CD28 共刺激 → 抑制 T 細胞活化數天心肌炎關鍵藥(+ruxolitinib 使死亡 60%→1/40)⚠ 機轉悖論:等於重新接上 ICI 阻斷的 CTLA-4 軸,理論上可能削弱抗腫瘤——保留給危及生命者
    JAK inhibitors
    (tofacitinib/ruxolitinib)    		阻斷 JAK-STAT → 廣譜細胞激素訊號最快:數小時–數天心肌炎(併 abatacept)、難治結腸炎/關節炎(新興)VTE/感染風險;廣譜免疫抑制之抗腫瘤疑慮
    ◆ B 細胞清除 / 免疫調節 / 細胞毒
    Rituximab (anti-CD20)清除 B 細胞 → ↓自體抗體慢:1–4 週+
    (B 細胞/抗體遞減)    		抗體媒介型:bullous pemphigoid、AIHA/ITP、部分腦炎HBV 再活化篩檢;感染
    IVIG多重免疫調節(Fc 受體阻斷、補體、抗個體基因型)快:1–5 天神經(GBS/MG)、AIHA/ITP、重症皮膚(併類固醇)血栓/腎/容積負荷;可與 PLEX 擇一
    ATG / PLEXATG=T 細胞清除;PLEX=血漿置換移除自體抗體快:數天
    (PLEX 立即移除抗體)    		重症/猛爆心肌炎、難治神經、aplastic anemia加護等級;ATG 輸注反應
    Cyclophosphamide烷化劑 → 廣譜免疫抑制1–2 週極難治(神經、肺炎、血管炎)骨髓抑制、出血性膀胱炎、生育
    選藥邏輯速記:結腸炎→infliximab 或 vedolizumab(後者腸道選擇性、抗腫瘤疑慮小);肝炎→MMF(不用 infliximab);心肌炎→abatacept±ruxolitinib(+ATG);神經(GBS/MG)→IVIG/PLEX;關節炎→TNFi/tocilizumab;血液(AIHA/ITP)→IVIG/rituximab;皮膚(BP)→rituximab。橫向共通疑慮:所有二線都是在「抑制免疫」與「保留抗腫瘤療效」間權衡,abatacept/JAK 因機轉直接對沖 ICI 而疑慮最大,vedolizumab 因局部作用疑慮最小。

    來源架構:ASCO Guideline 2021(J Clin Oncol 2021;39:4073)、NCCN Management of Immunotherapy-Related Toxicities、ESMO 2022。劑量以 prednisone 當量表示;methylpred = methylprednisolone。

    發生率來源:各 meta-analysis(El Osta Crit Rev Oncol Hematol 2017;Wang Front Oncol 2020 黑色素瘤網絡分析等)、CheckMate 067(NEJM 2019)、Postow NEJM 2018 綜述;均為約略區間,依癌別/劑量/研究而異,供類別間相對比較用。
